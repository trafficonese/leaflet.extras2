# removeConditionalLayer

removeConditionalLayer

## Usage

``` r
removeConditionalLayer(map, groups)
```

## Arguments

- map:

  A map widget object created from
  [`leaflet`](https://rstudio.github.io/leaflet/reference/leaflet.html).

- groups:

  A character vector of layer group names already added to the map.
  These layer groups will be conditionally displayed based on the
  specified `conditions`.
