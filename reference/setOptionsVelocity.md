# setOptionsVelocity

setOptionsVelocity

## Usage

``` r
setOptionsVelocity(map, layerId, options)
```

## Arguments

- map:

  the map widget

- layerId:

  the layer id

- options:

  see
  [`velocityOptions`](https://trafficonese.github.io/leaflet.extras2/reference/velocityOptions.md)

## Value

the new `map` object
