# clearAntpath

Clear all Antpaths

## Usage

``` r
clearAntpath(map)
```

## Arguments

- map:

  a map widget object, possibly created from
  [`leaflet`](https://rstudio.github.io/leaflet/reference/leaflet.html)()
  but more likely from
  [`leafletProxy`](https://rstudio.github.io/leaflet/reference/leafletProxy.html)()

## Value

the new `map` object
