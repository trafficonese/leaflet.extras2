# Provider for GeoSearch

Provider for GeoSearch

## Usage

``` r
geosearchProvider(
  type = c("OSM", "Bing", "Esri", "GeocodeEarth", "Google", "Here", "LocationIQ",
    "OpenCage", "Pelias", "Geoapify", "AMap", "GeoApiFr"),
  options = list()
)
```

## Arguments

- type:

  The provider name

- options:

  Optional named list of options and parameters

## Value

A list describing the provider config
