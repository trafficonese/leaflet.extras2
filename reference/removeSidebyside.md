# removeSidebyside

removeSidebyside

``` r
removeSidebyside(map, layerId = NULL)
```

## Arguments

- map:

  a map widget

- layerId:

  the layer id of the
  [`addSidebyside`](https://trafficonese.github.io/leaflet.extras2/reference/addSidebyside.md)
  layer

the new `map` object
