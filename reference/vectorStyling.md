# Default styles for OSM-based vector tiles

Layer-name styles for Mapbox, Nextzen, MapTiler / OpenMapTiles and
similar protobuf tiles. Override individual entries before passing to
[`addProtobuf`](https://trafficonese.github.io/leaflet.extras2/reference/addProtobuf.md).

## Usage

``` r
vectorStyling()
```

## Value

A named list of path options.
