# goForwardHistory

If possible, will go to next map extent. Pushes current extent to the
"back" stack.

## Usage

``` r
goForwardHistory(map)
```

## Arguments

- map:

  a map widget object created from
  [`leafletProxy`](https://rstudio.github.io/leaflet/reference/leafletProxy.html)

## Value

the new `map` object
