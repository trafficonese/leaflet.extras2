# Remove arrowheads from Lines by layerId

Remove arrowheads from Lines by layerId

## Usage

``` r
removeArrowhead(map, layerId)
```

## Arguments

- map:

  the map

- layerId:

  A single layerId or a vector of layerId's

## Value

A modified leaflet map
