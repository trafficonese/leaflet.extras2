# clearFuture

Resets the stack of future items.

## Usage

``` r
clearFuture(map)
```

## Arguments

- map:

  a map widget object created from
  [`leafletProxy`](https://rstudio.github.io/leaflet/reference/leafletProxy.html)

## Value

the new `map` object
