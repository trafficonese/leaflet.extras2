# disableContextmenu

Disable the contextmenu

## Usage

``` r
disableContextmenu(map)
```

## Arguments

- map:

  a map widget object created from
  [`leaflet`](https://rstudio.github.io/leaflet/reference/leaflet.html)

## Value

A leaflet map object
