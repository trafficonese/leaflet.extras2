# Remove the Sidebar

Remove the Sidebar

## Usage

``` r
removeSidebar(map, sidebar_id = NULL)
```

## Arguments

- map:

  A leaflet map widget

- sidebar_id:

  The id of the sidebar (per
  [`sidebar_tabs`](https://trafficonese.github.io/leaflet.extras2/reference/sidebar_tabs.md)).
  Defaults to `NULL` such that the first sidebar is removed.

## Value

the new `map` object
